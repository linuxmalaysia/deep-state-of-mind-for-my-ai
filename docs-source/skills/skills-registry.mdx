DSOM ships with 17 pre-built Agent Skills that cover the most common operational workflows across project setup, daily memory operations, document generation, and infrastructure management. Every skill is OKF-compliant, versioned in Git, and ready to use the moment you initialise a DSOM repository — no configuration required. Browse the categories below to find the right skill for your task, then trigger it by asking your AI to perform the work it describes.

## Skills by Category

<Accordion title="Project Setup — Initialise and scaffold DSOM projects">
  These skills handle the one-time operations you run when creating a new project or onboarding a new repository into the DSOM framework.

  | Skill | Path | When to Use |
  |:---|:---|:---|
  | **DSOM Bootstrap** | `.agents/skills/dsom-bootstrap/SKILL.md` | Use when starting a brand-new project and you need the full `.agents/` directory structure, Palace, and AGENTS.md rulebook created from scratch. |
  | **DSOM Project Cloner** | `.agents/skills/dsom-project-cloner/SKILL.md` | Use when you want to scaffold a new project by copying a validated DSOM baseline — all governance documents, skill stubs, and brain structure — into a new target path. |
  | **Initialise GitOps** | `.agents/skills/initialize-gitops/SKILL.md` | Use when establishing the foundational GitOps repository for a project, including the Genesis DSOM architecture, remote configuration, and initial commit structure. |
  | **Persona Injector** | `.agents/skills/persona-injector/SKILL.md` | Use when onboarding a new operator — this skill guides you through defining your Sovereign Persona profile and permanently injects it into the core `.agents/AGENTS.md` rulebook. |

  **Example trigger:** *"Bootstrap DSOM for my new infrastructure project."*
</Accordion>

<Accordion title="Daily Operations — SOD/EOD memory rituals and audits">
  These skills govern the daily cognitive lifecycle of your AI — loading context at the start of the day, externalising memory at the end, and auditing the Palace for integrity.

  | Skill | Path | When to Use |
  |:---|:---|:---|
  | **SOD Palace Sync** | `.agents/skills/sod-palace-sync/SKILL.md` | Use at the start of every working session. This Reanimation Ritual loads your workspace context — task list, walkthrough history, and Palace registry — so the AI picks up exactly where you left off. |
  | **EOD Palace Sync** | `.agents/skills/eod-palace-sync/SKILL.md` | Use at the end of every working session. This Hibernation Ritual externalises all session memory, decisions, and discoveries into the Palace and commits the state to Git. |
  | **Palace Auditor** | `.agents/skills/palace-auditor/SKILL.md` | Use when you suspect broken links, orphaned documents, or Palace drift. The auditor crawls your entire workspace, verifies all internal links, and reports on Palace health. |
  | **Forensic Log Audit** | `.agents/skills/forensic-log-audit/SKILL.md` | Use when you need to reconstruct the exact terminal commands executed in a previous AI session from raw conversation transcripts — useful after a context loss or session recovery. |

  **Example trigger:** *"Run the end-of-day Palace sync and push to Git."*
</Accordion>

## How to Trigger Any Skill

You do not need to reference a skill by name or path to use it. The DSOM semantic routing layer handles discovery automatically. To trigger any skill, simply ask your AI to perform the task the skill describes in natural language.

<Tip>
  The AI scans every skill's `description` field silently on every request. As long as your request semantically matches a skill's description, the skill loads and executes automatically — no special syntax required.
</Tip>

A few practical examples:

```
"Bootstrap DSOM for my new repository."
→ Triggers: DSOM Bootstrap

"Run the end-of-day sync and push my memory to Git."
→ Triggers: EOD Palace Sync

"Compile my proposal.md into a PDF."
→ Triggers: LaTeX Proposal Compiler

"Set up passwordless SSH to all my production nodes."
→ Triggers: SSH Passwordless Setup

"Extract all text from the vendor contract PDF."
→ Triggers: PDF Text Extractor
```

If you want to extend DSOM with your own workflows, see the [Creating Skills](/skills/creating-skills) guide to build a custom `SKILL.md` that follows the same OKF-compliant pattern.

DSOM Agent Skills are the executable memory of your AI. Instead of re-explaining the same workflows in every chat session, you encode that knowledge once into a `SKILL.md` file, and any compatible AI agent — Cursor, OpenHands, or any other OKF-aware provider — can discover and execute it on demand without human hand-holding or loss of context across sessions.

## What Is an Agent Skill?

An Agent Skill is a folder inside `.agents/skills/` that contains a single `SKILL.md` file. That file acts as an on-demand memory module: when a user's request semantically matches the skill's `description` field, the AI loads the full skill body into its active context and follows the embedded instructions to the letter.

```
.agents/skills/
└── my-custom-skill/
    └── SKILL.md      ← The memory module the AI loads
```

The skill file is a standard OKF-compliant Markdown document. It starts with YAML frontmatter (at minimum `name` and `description`) and continues with human-readable execution steps that the AI treats as a strict Standard Operating Procedure (SOP).

## How the AI Uses Skills

DSOM uses a **Progressive Disclosure** architecture to keep your AI fast and focused. Here is what happens behind the scenes every time you give your AI a task:

<Steps>
  <Step title="Silent Index Scan">
    The AI scans only the lightweight `name` and `description` fields from all registered skills — not the full file bodies. This initial pass costs almost no tokens.
  </Step>
  <Step title="Semantic Match">
    If your request semantically matches a skill's `description`, that skill is formally "triggered". The AI fetches the full `SKILL.md` payload only at this moment.
  </Step>
  <Step title="SOP Execution">
    The AI executes the skill's steps exactly as written — no guessing, no improvising. Quality gates and error-recovery paths defined inside the skill are enforced automatically.
  </Step>
</Steps>

<Tip>
  This Progressive Disclosure pattern compresses token overhead by up to **91%** compared to loading all skill content upfront. Your AI stays fast, cheap, and hyper-focused on the task at hand.
</Tip>

## The Skills Directory

All skills live under `.agents/skills/` in your repository. Each skill occupies its own named subdirectory:

```
.agents/skills/
├── dsom-bootstrap/
│   └── SKILL.md
├── eod-palace-sync/
│   └── SKILL.md
├── sod-palace-sync/
│   └── SKILL.md
└── <your-custom-skill>/
    └── SKILL.md
```

The directory name becomes the skill's identifier. Keep names lowercase, hyphen-separated, and descriptive of the workflow they encode.

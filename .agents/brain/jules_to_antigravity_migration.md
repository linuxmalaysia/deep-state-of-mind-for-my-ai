## 📦 Operational Data Export Architecture

All configuration, session history, and runtime environments managed within Jules were systematically mapped and extracted using the official export protocol:

### 1. Account & Environment Configuration
- `sources.json`: Complete inventory of 89 connected repositories (sources) registered under Jules across user and organisation scopes.
- `user-settings.json`: User-level preferences including Commit Authoring attribution settings (sole author, co-authored, or user-only) and reactive mode triggers.
- `env-variables.json`: Repository-level environment variable configurations required for build pipelines and tests (retained privately outside public version control).
- `scheduled-tasks.json`: Recurring maintenance jobs, automated PR schedules, and continuous dependency sweeps.

### 2. Repository Runtimes & Setup Scripts
For each connected repository, runtime configurations and setup instructions were recovered:
- `setup.sh`: Automated environment bootstrap scripts (`environmentSetupScript`).
- `test-command.txt`: Regression test commands and test runner parameters (`testCommand`).
- `memories.json` & `memories.md`: Consolidated repository-level memory entries capturing user corrections, preferences, and project patterns.

### 3. Comprehensive Session Corpus
- Over **400+ sessions** spanning Jules' history were indexed.
- For each session directory (`sessions/<id>/`):
  - `session.json`: Complete task payload, prompt description, lifecycle timestamps, and output commits.
  - `activities.json`: Full immutable activity steps representing tools invoked, file modifications, and planning cycles.
  - `patch-*.diff`: Unified diffs representing the exact code outputs and branch commits produced by Jules.
  - `summary.md`: Human-readable markdown summary capturing prompt, latest plan, code outputs, published commits, and activity statistics.
